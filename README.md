# ADSync (FunPay Auto-Delivery Sync) — плагин для FunPay Cardinal

Держит **одинаковое содержимое встроенной автовыдачи FunPay** (поле «секреты»/товары в самом лоте) у **нескольких лотов сразу** — через группы синхронизации.

> ⚙️ Для **FunPay Cardinal v0.1.17 и новее**. Команда в Telegram: **`/adsync`**.

## Зачем это нужно

Один и тот же пул товаров часто продаётся с нескольких лотов (разные игры/подкатегории). Проблема встроенной автовыдачи FunPay:

- Купили на лоте A → FunPay списала товар **только с лота A** → на лотах B и C товар остаётся и **может продаться второй раз** (двойная продажа = негативный отзыв/возврат).
- Пополнили товары на одном лоте через сайт → на остальных лотах их нет, пока не добавишь вручную.

**ADSync решает это:** лоты объединяются в группу с общим списком товаров. Продажа на любом лоте убирает товар со всех остальных; пополнение где-то одно расходится на всю группу.

## Возможности

- 🔗 **Группы синхронизации** — у каждой свой набор лотов и общий список товаров.
- ⚡ **Мгновенная синхронизация после продажи** — по событию нового заказа лота из группы (не дожидаясь плановой проверки).
- ⏱ **Периодическая проверка** (по умолчанию 60 сек., настраивается 30–900) — ловит изменения, сделанные вручную через сайт FunPay.
- 🧠 **Умное слияние**: чего нет хотя бы у одного лота группы — считается проданным/удалённым и убирается у всех; что добавлено хотя бы на одном — добавляется всем. Корректно даже если за один интервал изменения были сразу на нескольких лотах (продажа тут + пополнение там).
- 🎮 **Добавление лотов через меню**: ✅ — в группе, ⬜ — добавить, 🔒 — уже в другой группе (лот не может быть в двух группах). При добавлении товары лота сразу заменяются общим списком группы.
- 🥇 **Первый лот группы — источник**: при создании группы её товары берутся с первого лота (безопасно, ничего не «сливается» при первом проходе).
- 🖐 **Ручная синхронизация** — кнопка «🔄 Синхронизировать сейчас» с подробным отчетом в чат.
- 🔔 **Уведомления только о реальных изменениях** (без спама): сколько товаров стало, что убрано/добавлено, сколько лотов обновлено.
- ⚠️ **Диагностика**: предупреждение о лотах группы, у которых не включена встроенная автовыдача FunPay.
- 💾 Все настройки хранятся в `storage/plugins/ad_sync/settings.json`.

## Как это работает

1. Создайте группу (`/adsync` → ➕ Создать группу) и добавьте в неё лоты.
2. Первый добавленный лот задаёт исходный список товаров группы.
3. Дальше ADSync следит за группой:
   - **продажа** на любом лоте → проданный товар убирается со всех лотов группы (сразу после заказа + планово);
   - **пополнение/правка** товаров на любом лоте (через сайт FunPay) → изменения расходятся на всю группу;
   - изменения фиксируются в «базовом срезе», поэтому плагин понимает, **что именно** изменилось, даже если изменения были на нескольких лотах одновременно.
4. О каждом реальном изменении приходит уведомление в Telegram.

## Установка

1. Скачайте `ad_sync.py` из Releases (или скопируйте файл).
2. Положите его в папку `plugins/` вашего FunPay Cardinal:
   ```
   FunPayCardinal/
   └── plugins/
       └── ad_sync.py
   ```
3. Перезапустите Кардинал — плагин появится в списке (Telegram → ⚙️ → 🧩 Плагины).

| Действие | Как |
|---|---|
| Открыть меню | `/adsync` |
| Создать группу | ➕ Создать группу |

| Удалить группу | 🗑 Удалить группу (лоты и их товары не пострадают) |

## Тонкости и ограничения

- Синхронизируется только **содержимое** поля автовыдачи (список товаров). Флаг «автовыдача включена» у лотов плагин не переключает — включите его на лотах сами (при выключенном флаге будет предупреждение ⚠️).
- Лот может состоять **только в одной группе**.
- При добавлении лота в группу его текущие товары **заменяются** общим списком группы — если на лоте было что-то ценное, сначала перенесите это на лоты группы.
- Удаление лота из группы не меняет его товары — он остаётся с текущим списком.
- Товары сравниваются **посимвольно** (строки должны совпадать); порядок в общем списке сохраняется как в базовом срезе, новые товары добавляются в конец.
- Между покупкой и синхронизацией других лотов есть небольшое окно (секунды): заказ обрабатывается почти мгновенно, но абсолютно гарантировать отсутствие двойной продажи при одновременных покупках на разных лотах группы невозможно — это ограничение самого FunPay.
- Плагин читает поля лотов группы каждые N секунд (по одному запросу на лот) и сохраняет только изменённые лоты — трафик минимальный.

## Разработка / тесты

В репозитории есть `tests_plugin_ad_sync.py` — 72 проверки на моках (без сети): алгоритм слияния, первый проход, распространение продаж/пополнений, одновременные изменения, недоступные лоты, мгновенная синхронизация по заказу, весь Telegram-UI, нормализация настроек, уведомления. Запуск из корня FunPayCardinal:

```bash
python tests_plugin_ad_sync.py
```

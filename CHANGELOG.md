# 1.0.1

- Исправлен возврат последнего проданного товара: после ошибки записи/чтения оставшаяся на другом лоте копия больше не считается новым пополнением.
- Добавлен сохраняемый журнал отпечатков удалённых товаров. Запись на диск выполняется атомарно до изменения удалённых остатков.
- Загрузка настроек, синхронизация, сохранение и изменения через Telegram защищены общей блокировкой от параллельных потоков.
- Перед записью проверяется свежий остаток; при его изменении выполняется пересчёт. Результат сохранения перечитывается.
- Пустые лоты отключаются. После пополнения их нужно включить вручную.
- При отсутствии ID лота в событии заказа проверяются все включённые группы.
- Ошибки конкретных лотов отображаются в отчёте. Недоступный первый лот новой группы не заменяется случайной копией.
- Тесты запускаются из этого репозитория: 72 проверки существующих функций и 14 регрессионных тестов; добавлен CI для Python 3.10–3.12.

Это исправление обнаруженных ошибок синхронизации, а не гарантия от двух одновременных покупок: встроенная автовыдача FunPay выполняется до получения события плагином. Историю уже утраченных в 1.0.0 продаж восстановить автоматически нельзя.
